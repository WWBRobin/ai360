## 🧠 一、记忆增强：让 AI 记住你

### 你遇到的问题

> "每次开新对话，AI 就把我之前说的全忘了。"
> "我跟 AI 说了十遍我的需求，它还是理解错。"
> "我花了一小时调教好的 AI，关掉再打开又回到原点。"

### 为什么需要

AI 模型本身是无状态的——每次对话都是全新的。它"忘记"你不是因为笨，是因为**没有装记忆工具**。记忆增强工具让 AI 能跨会话记住你的偏好、项目上下文、历史决策。

### 推荐方案

#### 🥇 首选：claude-mem（Claude Code 用户）

- **平台**：Claude Code
- **GitHub**：72.4K Star
- **安装**：一行命令
- **免费**：完全免费开源
- **一句话评测**：Claude Code 用户的记忆标配，自动捕获跨会话上下文，零配置。

#### 🥈 跨平台首选：Mem0

- **平台**：任意 AI 应用（API 接入）
- **特点**：企业级记忆层，支持生产环境
- **免费额度**：有免费层
- **一句话评测**：如果你不只 Claude，想给多个 AI 都装记忆，Mem0 是最成熟的方案。

#### 🥉 中文生态：扣子知识库

- **平台**：扣子 Coze
- **特点**：中文友好，文档问答
- **免费**：扣子免费额度内可用
- **一句话评测**：扣子用户的首选，中文文档 RAG 效果好，但不是真正的"记忆"，更像是"知识库"。

### 怎么选

| 你的情况 | 推荐方案 |
|----------|---------|
| 我在用 Claude Code 写代码 | claude-mem |
| 我在用多个 AI 工具，想要统一记忆 | Mem0 |
| 我在用扣子，主要做中文场景 | 扣子知识库 |
| 我在用 Hermes | Hindsight（内置） |

## 🔍 二、联网搜索：让 AI 能上网

### 你遇到的问题

> "AI 给我的数据是 2024 年的，早就过时了。"
> "我让 AI 帮我查竞品信息，它说它不能联网。"
> "AI 给我编了一个不存在的 API 文档。"

### 为什么需要

AI 模型的知识有截止日期。今天的 AI 不知道昨天发生的事。联网搜索工具让 AI 能实时获取最新信息，避免"幻觉"（编造不存在的事实）。

### 推荐方案

#### 🥇 首选：Tavily

- **平台**：任意 AI（MCP 原生支持）
- **特点**：专为 AI 设计的搜索引擎
- **免费额度**：有免费层（每月 1000 次搜索）
- **一句话评测**：AI 搜索的黄金标准。返回结果直接是结构化的，AI 不用从网页里自己提取。MCP 原生支持，装上就能用。

#### 🥈 强力替代：Firecrawl

- **平台**：Claude Code / 跨平台
- **GitHub**：165K Star
- **特点**：网页抓取 + 搜索 + 浏览器自动化三合一
- **免费额度**：有免费层
- **一句话评测**：不只是搜索，还能帮你抓取整个网站的内容。适合需要深度网页数据的场景（爬竞品网站、抓文档等）。

#### 🥉 隐私选择：Brave Search MCP

- **平台**：任意 AI（MCP）
- **特点**：隐私优先，不追踪
- **免费额度**：有
- **一句话评测**：如果你在意隐私，Brave 是最好的搜索 MCP。结果质量略逊 Tavily，但不追踪你的查询。

### 怎么选

| 你的情况 | 推荐方案 |
|----------|---------|
| 我只想让 AI 能搜最新信息 | Tavily |
| 我需要 AI 帮我爬网站内容 | Firecrawl |
| 我在意隐私，不想被追踪 | Brave Search |
| 我在用扣子 | 扣子联网搜索插件（内置） |

## 📁 三、文件与代码：让 AI 能操作

### 你遇到的问题

> "AI 让我手动把文件内容复制粘贴给它。"
> "AI 生成了代码但没法直接运行测试。"
> "我有一堆 PDF 想让 AI 帮我读，但它说读不了。"

### 为什么需要

AI 默认只能处理文本对话。给它配上文件操作和代码执行工具，它就能读写文件、运行代码、解析文档——从"聊天机器人"变成"工作助手"。

### 推荐方案

#### 🥇 代码执行：E2B / Agent-Sandbox

- **平台**：任意 AI（API）
- **特点**：云端隔离沙箱，安全运行任意代码
- **免费额度**：有免费层
- **一句话评测**：让 AI 在安全的沙箱里跑 Python、装依赖、做数据分析。不用担心 AI 把你的电脑搞坏。

#### 🥈 文件操作：Filesystem MCP

- **平台**：任意支持 MCP 的 AI（Claude/Hermes/Cursor 等）
- **特点**：让 AI 直接读写你本地文件
- **免费**：完全免费
- **一句话评测**：AI 终于不用让你手动复制粘贴了。它能自己读你的文件、写代码到文件里。

#### 🥉 文档处理：Document Skills（Claude 官方）

- **平台**：Claude Code
- **特点**：创建和解析 PDF/DOCX/XLSX/PPTX
- **免费**：Claude 订阅内
- **一句话评测**：Claude 官方出品，PDF/Word/Excel/PPT 全格式支持。如果你用 Claude Code，这是文档处理的首选。

## 🔗 四、工具连接：让 AI 接外部世界

### 你遇到的问题

> "我想让 AI 帮我看 GitHub Issues，但它连不上。"
> "我想让 AI 帮我管 Jira 任务，但没有接口。"
> "我想让 AI 自动发 Slack 通知，不知道怎么接。"

### 为什么需要

AI 默认是个"孤岛"，只能跟你聊天。给它配上工具连接器，它就能操作你的 GitHub、Jira、Slack、Gmail、日历——变成真正的"数字助手"。

### 推荐方案

#### 🥇 首选：Composio

- **平台**：Claude Code / Codex / 跨平台
- **特点**：1000+ 应用连接（Jira/Slack/GitHub/Linear/Gmail...）
- **免费额度**：有免费层
- **一句话评测**：一个工具接通 1000+ 应用。装上之后 AI 就能帮你管项目、发消息、查邮件。

#### 🥈 轻量替代：Zapier AI Actions

- **平台**：ChatGPT / 跨平台
- **特点**：描述任务自动执行跨应用工作流
- **免费额度**：有免费层
- **一句话评测**：如果你已经用 Zapier，AI Actions 是最简单的接入方式。用自然语言描述"帮我从邮件提取任务创建到 Notion"，它就能自动执行。
