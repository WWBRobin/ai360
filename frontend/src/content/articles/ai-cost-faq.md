## Q3：Token是什么？怎么算？{#q3}

**Token是大模型计费的基本单位**，大致等于一个词或词的一部分。

**经验换算：**
- **英文：** 750个单词 ≈ 1000 Token
- **中文：** 1个汉字 ≈ 1-2 Token（中文比英文"贵"）

**计费方式：**

| 项目 | 是否收费 |
|------|---------|
| 你输入的内容（Prompt） | ✅ 按输入价格收费 |
| AI输出的内容（Completion） | ✅ 按输出价格收费 |
| 输出通常比输入贵 | ✅ 通常是输入价格的3-5倍 |

**举例计算：**
- 用GPT-4o处理100万字中文输入 + 生成20万字输出
- 输入：~200万Token × $5/百万 = $10
- 输出：~40万Token × $15/百万 = $6
- 总计：约$16

**省钱要点：**
- 输入便宜，输出贵 → 让AI输出精简（设max_tokens）
- 中文比英文贵 → 纯英文任务用英文Prompt
- 重复的System Prompt部分用缓存（见Q6）

## Q4：开源模型真的比闭源模型便宜吗？{#q4}

**结论：看用量。小用量用开源反而更贵（因为要自己部署）；大用量开源碾压式便宜。**

| 对比维度 | 闭源API（GPT/Claude） | 开源自部署（DeepSeek/Qwen/Llama） |
|---------|---------------------|-------------------------------|
| 初始成本 | $0，注册即用 | 需GPU服务器（~$5000+/月起） |
| 边际成本 | 按Token付费，永不归零 | 服务器固定成本，边际≈0 |
| 技术门槛 | 低，调API即可 | 高，需运维团队 |
| 适合谁 | 中小企业、个人、初期验证 | 大规模、固定批处理任务 |

**盈亏平衡点：** 当你的月API账单接近一台GPU服务器月租（数千美元）时，自部署开始划算。

**2025-2026最火的开源选择：**
- **DeepSeek** —— 性能接近旗舰，开源免费，API也极便宜
- **Qwen（通义千问）** —— 阿里开源，中文能力强
- **Llama系** —— Meta开源，生态成熟

**混合架构（最佳实践）：** 核心实时请求用闭源旗舰API保证质量，批量离线任务用开源本地部署控制成本。

## Q5：企业部署AI有哪些隐藏成本？{#q5}

**AI的成本远不止API调用费。** 完整的AI总拥有成本（TCO）包括：

| 成本类别 | 具体项目 | 占比参考 |
|---------|---------|---------|
| **模型/API费** | Token使用费、订阅费 | 30-50% |
| **算力硬件** | GPU服务器、云实例 | 20-40%（自部署） |
| **数据准备** | 数据清洗、标注、知识库构建 | 10-20% |
| **工程开发** | 集成开发、微调、RAG搭建 | 10-15% |
| **运维人力** | 模型维护、监控、迭代 | 5-10% |
| **安全合规** | 安全审计、合规审查 | 5-10% |

**常被忽略的隐性成本：**
1. **数据标注** —— 高质量标注员费用不菲
2. **Prompt工程** —— 反复调试Prompt消耗大量Token
3. **幻觉处理** —— AI出错后的人工校验/纠错成本
4. **合规成本** —— 数据出境审查、安全评估
5. **培训成本** —— 52%的员工从未接受过AI安全培训

**企业分阶段实施建议（避免一步到位超支）：**
- **阶段一：** 选最简单场景（内部知识问答、流程自动化），投入小见效快
- **阶段二：** 验证ROI后再扩展到核心业务
- **阶段三：** 大规模部署，考虑混合架构

## Q6：什么是Prompt缓存？能省多少钱？{#q6}

**Prompt缓存（Prompt Caching）= 把重复出现的提示词部分缓存，复用计算结果。**

像给AI装了"记忆模块"——遇到相似的输入直接复用，不用从头计算。

**能省多少？**

| 优化效果 | 数据 | 来源 |
|---------|------|------|
| 计算成本降低 | **最高90%** | AWS Bedrock官方 |
| 响应速度提升 | 响应时间缩短85% | 同上 |
| 首Token延迟降低 | 降低80% | OpenAI |
| OpenAI缓存折扣 | 成本降50% | 自动生效，无需改代码 |

**适用场景：**
- ✅ 客服系统（大量重复的System Prompt）
- ✅ 多轮对话（前面轮次的上下文可缓存）
- ✅ 固定文档 + 变量查询（RAG场景）
- ✅ 代码助手（大型代码库作为上下文）

**实际案例：**
- Adobe Acrobat AI助手用Prompt缓存后，文件处理响应时间缩短72%
- Argo Labs语音客服结合智能路由+缓存，大幅降本增效

**怎么用：**
- **OpenAI：** 自动生效，无需改代码
- **AWS Bedrock：** 需配置启用
- **Anthropic：** 支持提示缓存，但有额外配置开销

## Q7：批处理API（Batch API）怎么省钱？{#q7}

**批处理API = 把不急的请求攒成一批，24小时内统一处理，价格直接打5折。**

| 对比 | 实时API | 批处理API |
|------|--------|----------|
| 响应时间 | 秒级 | 24小时内 |
| 价格 | 标准价 | **标准价的50%** |
| 适合场景 | 用户对话、实时分析 | 数据标注、批量总结、内容生成 |

**OpenAI批处理示例：**
```bash
curl https://api.openai.com/v1/batches \
  -H "Authorization: Bearer $API_KEY" \
  -d '{
    "input_file_id": "your_batch_input_file",
    "endpoint": "/v1/chat/completions",
    "completion_window": "24h"
  }'
```

**典型省钱场景：**
- 批量翻译1000篇文档 → 实时$50，批处理$25
- 生成商品描述10000条 → 实时$200，批处理$100
- 历史数据总结分析 → 不需要实时，批处理最佳

**注意：** 部分中转站/代理商可能不支持批处理，确认后再用。

## Q8：小企业/个人开发者怎么控制AI成本？{#q8}

**8条实操省钱策略（按效果排序）：**

| 策略 | 节省幅度 | 难度 | 说明 |
|------|---------|------|------|
| 1. 模型分级路由 | ⭐⭐⭐⭐⭐ | 中 | 简单任务用Flash/Haiku，复杂任务才用旗舰 |
| 2. Prompt缓存 | ⭐⭐⭐⭐⭐ | 低 | 重复Prompt自动缓存，省50-90% |
| 3. 批处理API | ⭐⭐⭐⭐ | 低 | 不急的任务攒批，省50% |
| 4. 设max_tokens限制 | ⭐⭐⭐⭐ | 低 | 防止AI输出冗长内容烧Token |
| 5. 结构化输出 | ⭐⭐⭐ | 低 | 要求JSON/简洁格式，减少输出量 |
| 6. 开源模型替代 | ⭐⭐⭐⭐⭐ | 高 | DeepSeek/Kimi替代旗舰，省20-50倍 |
| 7. 应用层缓存 | ⭐⭐⭐ | 中 | 相同问题用Redis缓存答案 |
| 8. 订阅代替API | ⭐⭐⭐ | 低 | 中等用量下$20订阅比API便宜 |

**模型分级路由示例：**

| 任务类型 | 推荐模型 | 理由 |
|---------|---------|------|
| 复杂推理/代码/高质量创作 | Claude Opus 4 / GPT-4o | 质量优先 |
| 日常编程/文本/通用 | Claude Sonnet 4 | 最佳平衡 |
| 简单问答/摘要/格式转换 | Claude Haiku / GPT-4o-mini / DeepSeek Flash | 够用即可 |
| 原型验证/内部测试 | 最便宜的模型 | 非生产环境 |

> 💡 **核心心法：** 对绝大部分任务（样板代码、简单函数、文档、初稿），旗舰模型带来的边际提升不值得50倍成本。**"足够好"就是最优解。**

## Q9：AI成本未来会降吗？{#q9}

**短期看分两极，长期看整体下降。**

**现实情况（2025-2026年）：**

| 模型层级 | 价格趋势 | 说明 |
|---------|---------|------|
| 上一代模型 | 持续大幅降价 | GPT-3.5比GPT-4便宜26倍 |
| 当前旗舰模型 | **基本没降** | "最强模型"价格始终差不多 |
| 开源模型 | 碾压式低价 | Kimi/DeepSeek比旗舰便宜20-50倍 |

**为什么会这样？** 有一个残酷现实：用户只对"最强模型"有需求。你打开Claude不会说"今天用个差一点的版本省点钱"。最强模型的价格反映的是当前推理技术的真实成本——它就像"2025年的凯美瑞"，厂商指导价不会因为"1995年的思域降价了"而降。

**但好消息是：**
1. 开源模型性能在快速追上，逼着旗舰降价
2. Prompt缓存、批处理等优化技术越来越成熟
3. 模型小型化（蒸馏）让"够用"的模型越来越便宜
4. 硬件进步（专用AI芯片）降低推理成本

**预测：** 到2027年，大多数日常AI任务的成本将降至现在的1/5-1/10，但最新旗舰模型仍会保持较高溢价。

## Q10：有哪些常见的"烧钱"误区？{#q10}

**TOP 5 Token烧钱陷阱：**

| 误区 | 后果 | 正确做法 |
|------|------|---------|
| 所有任务都用旗舰模型 | 账单膨胀20-50倍 | 模型分级路由，简单任务用便宜模型 |
| 不设max_tokens | AI输出冗长，输出Token是输入3-5倍贵 | 设合理上限，要求简洁输出 |
| 重复发送长System Prompt | 每次都全量计算 | 用Prompt缓存 |
| 实时处理不急的任务 | 按全价付费 | 批处理API省50% |
| 不做应用层缓存 | 相同问题反复调用 | Redis缓存标准答案 |

**一句话总结：** AI成本管理的核心不是"用最便宜的模型"，而是**"让每个任务用对模型，用尽所有优化手段"**。
