## 一、扣子是什么？能做什么？

**扣子（Coze）** 是字节跳动推出的 AI 智能体开发平台，海外版叫 Coze，国内版叫"扣子"。它的核心定位是：**让不会编程的人也能搭建 AI 智能体。**

### 扣子能做什么？

| 能力 | 说明 | 典型场景 |
|------|------|----------|
| **AI 对话** | 基于大模型的多轮对话 | 客服、陪聊、问答机器人 |
| **知识库** | 上传文档，AI 基于文档回答 | 产品手册问答、FAQ |
| **插件** | 调用外部 API 和工具 | 查天气、搜新闻、查数据库 |
| **工作流** | 多步骤自动执行 | 数据采集→分析→生成报告 |
| **多渠道发布** | 一键发布到各平台 | 飞书、微信、抖音、API |

### 扣子支持的大模型

扣子内置了多款主流大模型：豆包（Doubao）、DeepSeek、通义千问、智谱 GLM 等。搭建智能体时可以自由切换模型，**大部分功能在免费额度内即可使用**。

## 二、第一步：注册与创建智能体

### 1. 注册账号

打开扣子官网 **coze.cn**（国内版）或 **coze.com**（海外版），支持手机号、抖音、飞书等多种方式登录。

### 2. 创建智能体

1. 登录后点击左侧导航栏的 **"创建智能体"**
2. 填写基本信息：
   - **名称**：给你的智能体起个名字（如"小助手"）
   - **描述**：一句话说明它的用途
   - **图标**：可点击 AI 自动生成，或本地上传图片
3. 点击 **"确认"**，进入编辑页面

### 3. 认识编辑界面

进入编辑页后，你会看到三个区域：

- **左侧（编排区）**：选择运行模式、编写人设与回复逻辑
- **中间（工具区）**：选择大语言模型、添加插件、知识库、工作流
- **右侧（调试区）**：实时测试对话效果

### 运行模式怎么选？

| 模式 | 适合场景 | 复杂度 |
|------|----------|--------|
| **单 Agent（LLM 模式）** | 简单问答、对话 | ⭐ 最简单 |
| **单 Agent（工作流模式）** | 固定流程的多步骤任务 | ⭐⭐ |
| **多 Agents** | 复杂的、需要分工协作的任务 | ⭐⭐⭐ |

> **新手建议**：先从"单 Agent（LLM 模式）"开始，熟练后再尝试工作流和多 Agents。

## 三、第二步：编写提示词（Prompt）

提示词是智能体的"灵魂"——它决定了 AI 扮演什么角色、怎么回答、有哪些限制。

### 1. 在哪里写？

在左侧编排区的 **"人设与回复逻辑"** 框中填写。

### 2. 提示词模板（直接套用）

一个好的提示词应该包含三个部分：**角色 + 技能 + 限制**。

```
# 角色
你是一个【客服助手】，专门帮助用户解答关于【XX产品】的使用问题。

# 技能
1. 熟悉产品的所有功能模块和使用方法
2. 能够根据用户描述的问题快速定位原因
3. 用简洁、友好的语言给出解决方案
4. 遇到无法解决的问题，引导用户联系人工客服

# 限制
- 只回答与产品相关的问题，不闲聊
- 回答控制在 200 字以内
- 如果不确定答案，明确告知用户"我需要确认一下"，不要编造
- 使用中文回复
```

### 3. 让 AI 帮你优化提示词

写完后，点击右上角的 **"优化"** 按钮，Coze 会自动帮你把简单提示词扩展成结构化的专业提示词。比如你输入"你是 AI 助手，擅长总结和聊天"，优化后会自动按角色、技能、限制三方面扩展。

### 4. 选择大模型

在中间区域选择大语言模型。推荐选择 **32K 上下文** 的版本（32K = 能处理约 32000 个 token，适合处理长文档和复杂任务）。日常对话可以选择豆包 Function Call 模型。

## 四、第三步：添加知识库

**知识库**是让智能体"懂你业务"的关键。上传你自己的文档后，AI 会基于文档内容回答，而不是凭空编造。

### 1. 支持的格式

扣子知识库支持：PDF、Word、Excel、TXT、Markdown、网页 URL（自动爬取）、Notion 等。

### 2. 如何添加知识库？

1. 在编辑页中间区域，找到 **"知识库"** → 点击 **"+"**
2. 选择添加方式：
   - **上传文件**：直接拖入 PDF/Word/Excel
   - **输入网址**：填入网页 URL，系统自动爬取内容
   - **在线编辑**：手动输入文本
3. 系统会自动对文档进行分段、向量化处理
4. 处理完成后，智能体就能基于这些内容回答问题了

### 3. 知识库最佳实践（重要！）

知识库质量直接影响 AI 回答质量。以下是 4 条核心原则：

| 原则 | 说明 | 反面案例 |
|------|------|----------|
| **一文一主题** | 每个文档只讲一个主题 | 把所有产品信息塞进一个 PDF |
| **结构清晰** | 用标题、列表、表格组织内容 | 大段文字没有分段 |
| **去除无关内容** | 不放旧版本说明、聊天记录、错误日志 | 知识库里有测试数据 |
| **加前置说明** | 文档开头写清楚适用范围和版本 | 文档没有版本信息 |

### 4. 推荐的知识库结构

**客服场景 → FAQ 知识库**
```
Q: 产品怎么注册？
A: 打开官网，点击右上角"注册"...

Q: 忘记密码怎么办？
A: 点击登录页"忘记密码"...
```

**企业场景 → SOP 操作规范库**
```
# 新员工入职流程
## 第1步：提交材料
...
## 第2步：领取设备
...
```

## 五、第四步：使用插件增强能力

智能体默认只能"聊天"，加上插件后就能"行动"——联网搜索、查天气、生成图片、读取数据库。

### 1. 添加内置插件

扣子提供了大量官方插件，在编辑页 → **插件** → 点击 **"+"** 即可浏览和添加。

常用插件包括：

- 🔍 **搜索插件**：联网搜索最新信息（知识库没有的内容）
- 🖼️ **图片理解**：识别用户上传的截图
- 🌤️ **天气查询**：获取实时天气
- 📰 **新闻搜索**：获取最新资讯
- 🔗 **LinkReader**：读取网页链接内容

### 2. 添加自定义 API（高级）

如果你想连接公司系统或第三方平台（如飞书、Notion、Slack），可以用**自定义工具**：

1. 打开智能体 → 工具 → 添加自定义工具
2. 填写 API URL（支持 GET / POST / PUT / DELETE）
3. 设置 Header（如 `Authorization: Bearer xxx`）
4. 设置请求参数（Body）
5. 定义响应结构
6. 测试通过后保存

> **小贴士**：自定义 API 需要一定的开发基础。如果你不熟悉 API 调用，先用官方插件练手。

## 六、第五步：用工作流实现复杂逻辑

当你的任务需要**多个步骤按顺序执行**时（比如"搜索→分析→生成报告"），就需要用到**工作流**。

### 工作流是什么？

工作流是一种可视化编程方式——你用拖拽的方式把多个"节点"连起来，每个节点做一件事，数据按顺序从一个节点流向下一个节点。

### 常用节点类型

| 节点 | 功能 |
|------|------|
| **开始** | 定义输入参数 |
| **LLM** | 调用大模型生成文本 |
| **代码** | 执行 JavaScript/Python 逻辑 |
| **条件判断** | 根据条件走不同分支 |
| **插件** | 调用外部 API |
| **知识库** | 检索知识库内容 |
| **结束** | 输出最终结果 |

### 实战示例：新闻分析工作流

```
用户输入关键词
    ↓
[搜索插件] 联网搜索相关新闻
    ↓
[LLM 节点] 提取关键信息、生成摘要
    ↓
[代码节点] 格式化输出
    ↓
返回结构化分析报告
```

### 如何创建工作流？

1. 在编辑页选择运行模式为 **"单 Agent（工作流模式）"**
2. 或在多 Agents 模式下创建工作流
3. 拖拽节点到画布，连线定义流程
4. 每个节点配置参数和提示词
5. 在右侧调试区测试

## 七、第六步：发布与部署

智能体搭好后，需要发布才能使用。

### 1. 发布步骤

1. 点击编辑页右上角的 **"发布"** 按钮
2. 填写发布记录（写了什么改动）
3. 选择发布渠道
4. 点击确认发布

### 2. 支持的发布渠道

| 渠道 | 说明 |
|------|------|
| **扣子商店** | 发布到扣子平台，其他用户可以使用 |
| **飞书机器人** | 在飞书中通过机器人对话使用 |
| **微信公众号** | 接入公众号后台 |
| **微信客服** | 接入微信客服系统 |
| **抖音** | 接入抖音私信 |
| **API** | 生成 API 接口，集成到自己的网站/APP |
| **Web SDK** | 嵌入网页，作为聊天窗口 |

### 3. 发布后调试

发布后并不意味着结束。你应该持续观察智能体的表现，根据用户反馈调整提示词、补充知识库、优化工作流。

## 八、实战案例：3 个可直接照搬的智能体

### 案例 1：智能客服

- **提示词**：你是一个专业的客服助手，服务【XX产品】用户
- **知识库**：产品使用手册 + FAQ 表格
- **插件**：搜索插件（兜底）、图片理解（识别报错截图）
- **欢迎语**："你好！我是 XX 客服小助手，有问题随时问我 🎉"

### 案例 2：内容创作助手

- **提示词**：你是一个爆款文案写手，擅长写小红书/抖音文案
- **知识库**：品牌调性指南 + 爆款文案模板
- **插件**：搜索插件（找热点素材）
- **工作流**：输入产品信息 → 分析卖点 → 生成 3 版文案 → 选最优

### 案例 3：数据质检助手

- **提示词**：你是数据质量审核员，负责检查数据完整性和准确性
- **工作流**：输入数据 → 规则检查 → 异常标记 → 生成质检报告
- **插件**：自定义 API（连接数据库）

## 九、常见问题与避坑指南

### Q1：扣子收费吗？

扣子提供**免费额度**，个人用户日常使用基本够用。企业级功能和高频调用可能需要付费。具体以官网最新定价为准。

### Q2：智能体回答不准确怎么办？

- ✅ 检查知识库文档质量（是否结构清晰、一文一主题）
- ✅ 优化提示词（增加限制条件、给出示例）
- ✅ 调整模型（尝试不同大模型，效果有差异）
- ✅ 在提示词中加入"如果不确定就说不知道"

### Q3：知识库上传后 AI 还是不用？

- 检查知识库是否处理成功（分段是否正常）
- 在提示词中明确要求"优先使用知识库中的信息回答"
- 确认问题和知识库内容相关

### Q4：插件调用失败？

- 检查 API 地址是否正确
- 检查 Header（尤其是 Authorization）是否有效
- 在插件调试界面单独测试

### Q5：单 Agent 和多 Agents 怎么选？

- 任务逻辑简单（一问一答）→ **单 Agent（LLM 模式）**
- 有固定的多步骤流程 → **单 Agent（工作流模式）**
- 任务复杂、需要多个角色协作 → **多 Agents**
