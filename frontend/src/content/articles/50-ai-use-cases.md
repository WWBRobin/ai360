## 办公提效篇

<a id="office"></a>

### 场景 1：会议纪要自动生成

**痛点**：开了一小时会，整理纪要又要半小时。

**AI 怎么做**：把会议录音转成文字（或直接输入文字记录），让 AI 提炼。

```
以下是会议记录，请帮我整理成正式会议纪要：
- 格式：会议信息 + 讨论要点 + 决议事项 + 待办任务（责任人/截止日期）
- 语言：简洁正式
[粘贴会议文字记录]
```

### 场景 2：周报/月报一键生成

**痛点**：每周写周报像挤牙膏。

```
帮我写本周周报，我的工作内容如下：
1. [完成了什么]
2. [完成了什么]
3. [遇到的问题]
格式要求：本周完成 / 进行中 / 下周计划，每项 2-3 句话，突出成果和数据
```

### 场景 3：邮件起草与回复

**痛点**：写邮件措辞反复修改。

```
帮我写一封邮件给客户，背景：
- 目的：通知项目延期一周
- 原因：第三方接口出了问题，已在协调
- 语气：专业、抱歉但不过度道歉、给出新时间线
- 200 字以内
```

### 场景 4：Excel 公式生成

**痛点**：记不住复杂的 Excel 公式。

```
我有一个 Excel 表格：
- A 列是销售日期，B 列是销售额
- 我想计算：每个月的总销售额
请告诉我具体的公式，并解释每个参数的含义。
```

### 场景 5：PPT 大纲与内容生成

**痛点**：做 PPT 不知道写什么。

```
帮我做一个 10 页 PPT 的大纲，主题是"2025 年部门工作总结"：
- 第 1 页：标题页
- 第 2 页：年度概览（3 个核心数据）
- 第 3-7 页：5 大重点项目回顾
- 第 8 页：问题与挑战
- 第 9 页：明年计划
- 第 10 页：感谢页
每页给我标题 + 3 个要点 + 建议配图方向
```

### 场景 6：长文档/合同审阅

**痛点**：几十页的合同看不懂重点。

```
请审阅以下合同，重点关注：
1. 对我不利的条款（标红）
2. 可能的法律风险
3. 建议修改或补充的条款
[上传合同 PDF]
```

> ⚠️ AI 审阅仅供参考，重要合同请咨询专业律师。

### 场景 7：竞品分析报告

**痛点**：调研竞品耗时耗力。

```
帮我分析以下 3 个竞品：[产品 A]、[产品 B]、[产品 C]
请从以下维度对比：
- 核心功能
- 定价策略
- 目标用户
- 优势与劣势
输出为对比表格，并给出 1 条战略建议。
```

### 场景 8：数据报表解读

**痛点**：面对一堆数字看不出趋势。

```
以下是上季度销售数据，请帮我：
1. 找出 3 个关键趋势
2. 标注异常值并解释可能原因
3. 给出 2 条数据驱动的建议
[粘贴数据]
```

### 场景 9：项目计划制定

**痛点**：排期总是遗漏环节。

```
我要做一个新项目：[项目描述]
- 团队：3 人
- 周期：4 周
- 预算：5 万元
请用甘特图思路制定项目计划：
- 拆解为具体任务（含依赖关系）
- 每个任务的负责人和天数
- 关键里程碑
输出为表格
```

### 场景 10：多语言翻译与本地化

**痛点**：机器翻译太生硬。

```
请将以下中文翻译成商务英语，要求：
- 语气：正式商务邮件
- 避免中式英语
- 专业术语使用行业标准表达
- 翻译后附上 3 处关键表达的说明
[中文原文]
```

### 场景 11：会议/活动策划

```
帮我策划一场公司年会，背景：
- 人数：50 人
- 预算：3 万元
- 主题：科技创新
请输出：流程安排表（含时间段/环节/负责人）+ 预算分配表 + 物料清单
```

### 场景 12：公文/通知撰写

```
帮我写一份公司内部通知：
- 事项：中秋节放假安排
- 时间：9 月 15-17 日放假，9 月 14 日调休上班
- 语气：正式规范
- 格式：标准公文格式
```

## 学习成长篇

<a id="study"></a>

### 场景 13：费曼学习法——让 AI 当你的学生

```
我正在学习[某个概念]，请你扮演一个完全不懂的人，
我来给你讲解，你听完后提出 3 个你不懂的问题，
帮助我发现自己理解的漏洞。
```

### 场景 14：外语对话练习

```
你是一位咖啡店服务员，我是顾客。
我们来用英语进行点单对话：
- 你先开始打招呼
- 我的水平：初级，请用简单词汇
- 如果我表达有误，请在对话结束后纠正我
```

### 场景 15：论文/文献阅读助手

```
请帮我阅读以下论文，输出：
1. 研究问题（1 句话）
2. 核心方法（3 个要点）
3. 主要发现（3 条）
4. 局限性（2 条）
5. 跟我研究方向相关的启示（2 条）
[上传论文 PDF]
```

### 场景 16：考试复习——知识点提问

```
我要参加[考试名称]，帮我制定复习策略：
- 考试范围：[列出科目/章节]
- 距离考试：2 周
- 每天可复习：3 小时
请输出：每日复习计划 + 每章重点 + 5 道模拟题（附答案和解析）
```

### 场景 17：读书笔记生成

```
我刚读完《[书名]》，请帮我：
1. 总结全书核心观点（5 条）
2. 提取 3 个最打动我的金句（附页码范围）
3. 给出 3 个"读完这本书后可以采取的行动"
```

### 场景 18：概念可视化解释

```
请用"做菜"的比喻来解释"机器学习"，
让我这种零基础的人也能理解。
然后给一个生活中的小例子。
```

### 场景 19：编程学习陪练

```
我在学 Python，遇到了这个报错：
[粘贴错误信息]
请：
1. 解释这个错误是什么意思
2. 告诉我怎么修（给代码）
3. 解释为什么会出错（帮我理解原理）
4. 给一个类似的小练习巩固
```

### 场景 20：写作修改与提升

```
请帮我修改以下文章，要求：
- 保持我的核心观点不变
- 改善逻辑流畅度和语言表达
- 标注修改了哪些地方及原因
- 指出 3 个可以继续提升的方向
[粘贴你的文章]
```

### 场景 21：知识点联想记忆

```
我要记住以下知识点：[列出知识点]
请用"记忆宫殿"或"故事联想法"帮我设计一套记忆方案，
越生动有趣越好。
```

### 场景 22：制定技能学习路线图

```
我想学习[技能名称，如：数据分析/视频剪辑/UI 设计]
- 我的水平：零基础
- 目标：[达到什么程度]
- 时间：每天 1 小时，持续 3 个月
请输出一份路线图：
- 分为几个阶段
- 每个阶段学什么（具体资源类型）
- 每阶段结束的"验收标准"
```

## 日常生活篇

<a id="life"></a>

### 场景 23：一周饮食计划

```
帮我制定一周饮食计划：
- 人数：2 大人 1 小孩
- 限制：小孩对花生过敏
- 偏好：中餐为主，少油少辣
- 预算：每天 100 元以内
输出：7 天 × 3 餐表格，附购物清单
```

### 场景 24：旅行行程规划

```
帮我规划 5 天日本东京旅行：
- 出行时间：10 月（赏枫季节）
- 预算：1.5 万元（含机票住宿）
- 偏好：文化体验 + 美食，不去网红打卡点
- 同行：夫妻 2 人
输出：每日行程表（含交通/景点/餐厅/预算），住宿建议
```

### 场景 25：健身计划定制

```
帮我制定健身计划：
- 我的身体数据：身高 175cm，体重 80kg
- 目标：3 个月减脂 5kg
- 条件：家里锻炼，有哑铃，每周 4 次，每次 45 分钟
- 旧伤：左膝盖有旧伤，避免深蹲
输出：4 周训练计划表 + 饮食建议
```

### 场景 26：家居整理断舍离

```
我要整理一个堆满东西的书房，请：
1. 给我一个分类整理的流程（先做什么后做什么）
2. 判断"留还是扔"的 5 条标准
3. 整理后如何维持的 3 个习惯
```

### 场景 27：购物决策助手

```
我想买一台扫地机器人，预算 2000-3000 元。
请帮我：
1. 列出这个价位值得考虑的 3 款
2. 从吸力/续航/智能规划/售后 4 个维度对比
3. 根据我家情况（80 平、有猫、木地板）推荐 1 款
```

> 💡 用 AI 联网搜索功能获取最新型号和价格。

### 场景 28：菜谱生成（冰箱有什么做什么）

```
我冰箱里有：鸡蛋、西红柿、青椒、豆腐、剩米饭
请给我 3 个能用这些食材做的菜谱：
- 每个菜谱附步骤（不超过 5 步）
- 标注烹饪时间和难度
- 给一个"如果再加一样食材会更好"的建议
```

### 场景 29：理财记账分析

```
以下是我上个月的开支记录，请帮我：
1. 分类统计（餐饮/交通/购物/娱乐/固定支出）
2. 找出 3 个可以节省的地方
3. 给出适合我的预算建议
[粘贴开支明细]
```

### 场景 30：日程/时间管理

```
这是我明天要做的事，请帮我排一个时间表：
- 9 点开部门周会（1 小时）
- 要写完一份报告（预计 3 小时）
- 回复积压的 15 封邮件（预计 1 小时）
- 午餐和休息
- 下午 3 点有个客户电话（30 分钟）
- 6 点前要接孩子
原则：高效时段做需要专注的事，碎片时间做杂事
```

### 场景 31：礼物推荐

```
帮我推荐礼物：
- 对象：妈妈，55 岁
- 场合：生日
- 预算：500 元
- 妈妈的兴趣： gardening、追剧、养生
- 去年送过：按摩仪
请推荐 5 个不同方向的选项，说明推荐理由
```

### 场景 32：子女教育辅导

```
我的孩子上小学三年级，正在学分数概念但听不懂。
请用生活中的例子教他理解"分数"，要求：
- 用切披萨、分巧克力等具象比喻
- 设计 3 道由浅入深的小练习
- 如果他还是不懂，给一个备选解释方式
```

### 场景 33：宠物养护咨询

```
我刚养了一只 3 个月大的橘猫，请给我一份新手养猫指南：
- 必备物品清单（附优先级）
- 喂养时间表和食量参考
- 需要打的疫苗和驱虫计划
- 常见异常表现和应对方法
```

### 场景 34：个人健康咨询（初步参考）

```
我最近总是下午犯困，晚上又睡不好。
请从以下角度分析可能的原因：
1. 饮食因素
2. 作息因素
3. 环境因素
并给出 5 条可以尝试的改善建议。
```

> ⚠️ AI 不能替代医生诊断。持续不适请就医。

## 创意创作篇

<a id="create"></a>

### 场景 35：短视频脚本创作

```
帮我写一个 60 秒抖音短视频脚本，主题是"打工人的一周"：
- 风格：搞笑、共鸣、有反转
- 结构：钩子(3 秒) + 铺垫(20 秒) + 高潮(20 秒) + 反转(10 秒) + 引导互动(7 秒)
- 输出：分镜表（时间/画面描述/台词/字幕/BGM 建议）
```

### 场景 36：小红书爆款文案

```
帮我写一篇小红书种草文案，产品是[产品名]：
- 人设：真实用户，不是广告

- 标题给 3 个版本让我选
- 正文 300-400 字
- 给 10 个相关话题标签

### 场景 37：AI 绘画提示词

```
帮我生成一段 Midjourney/Stable Diffusion 的提示词：

请给我 3 个反转方案，每个附：反转设计 + 为什么有效 + 对后续情节的推动

### 场景 39：播客/视频选题策划

请帮我策划下 5 期的选题：

- 要求：每期一个具体场景，标题要有吸引力
- 附每期的 3 个讨论要点和 1 个互动话题
```

### 场景 40：品牌起名与 slogan

```
帮我做一个新品牌的命名：
- 产品：面向年轻人的功能性饮料
- 关键词：活力、自然、科技感
- 要求：中文名 + 英文名，好记、好传播
- 给 10 个方案，每个附命名理由
然后从中选 3 个，各写一句 slogan
```

### 场景 41：歌词/诗/文案创作

```
帮我写一首关于"深夜加班"的现代诗：
- 风格：写实、有画面感、不矫情
- 4-6 段
- 最后一句要有余味
```

### 场景 42：活动/朋友圈文案

```

- 版本 1：低调感恩型

每版 50 字以内，附配图建议

```

### 场景 49：面试模拟

```
你是一位[职位名称]的面试官，请模拟一场面试：
- 我有 5 年工作经验，上一份工作在[公司类型]

## 常见问题 FAQ

### Q：这些场景需要付费工具吗？

**不需要。** 以上 50 个场景用 DeepSeek、Kimi、豆包的免费版都能完成。图片生成推荐通义千问（免费额度充足）。

### Q：提示词必须这么长吗？

不是。上面的模板是"完整版"，展示的是**最佳实践**。日常使用时，你只需要记住核心结构：**角色 + 任务 + 限制 + 格式**。熟练后 2-3 句话就能搞定。

### Q：AI 生成的内客可以直接用吗？

**文案、大纲、初稿**可以直接用或微调。**涉及事实、数据、法律、医疗**的内容一定要核实。AI 是"超级初稿生成器"，不是"最终答案"。

### Q：我试了但效果不好怎么办？

效果不好通常是 3 个原因：
1. **提示词太模糊** → 参考本文模板，加具体限制
2. **模型不对** → 换一个 AI 工具试试
3. **期望太高** → AI 是助手不是专家，给它"具体的、可执行的"任务

### Q：50 个场景看不完怎么办？

不用全看。**找到跟你最相关的 3-5 个，今天就去试。** 用起来比看完整更重要。可以参考上方"按角色推荐"表格。

### Q：这些场景有风险吗？

有。特别注意：
- **不要输入敏感信息**（密码、身份证、公司机密）
- **法律/医疗/投资建议仅供参考**，重要决策咨询专业人士
- **AI 生成内容可能存在偏差**，发布前人工审核

50 个场景看起来很多，但核心逻辑只有一个：
